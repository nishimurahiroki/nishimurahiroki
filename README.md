# Hiroki Nishimura

関西大学 総合情報学部

大学での学習に加え、オンライン柔道学習サービス「Gatame Kosen Online」の運営に携わりながら、
実際のサービス上の課題を解決するWebアプリケーションを開発しています。
Gatame Kosen OnlineではHPやLP作成、YouTube撮影・編集などを行っています。
https://www.kosenjudoonline.com/

## Projects

### Gatame Kosen Learning Pass Navigator

ユーザーの柔道・BJJ経験や技術的課題を診断し、
個別の学習パスを生成するWebアプリケーションです。

サービス運営から課題を発見し、
ターゲット・利用タイミング・必要機能・UXを設計しました。

→ [Repository](https://github.com/nishimurahiroki/gatame-kosen-learning-pass-navigator)

### Gatame Diagnosis

Gatame Kosen Onlineのユーザー向け診断アプリケーションです。

→ [Repository](https://github.com/nishimurahiroki/gatame-diagnosis)

### Judo Timer（プロトタイプ）
